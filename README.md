# ChatGPT Desktop Concept

A complete, local-first React 19 and TypeScript desktop interface built with the real Astryx 0.7.0 packages. The application entry point is `src/App.tsx`.

## Run

- `npm install`
- `npm run dev`
- `npx tsc --noEmit`
- `npm run build`
- `npx playwright test`

For a fresh test environment, install Chromium once with `npx playwright install --with-deps chromium`. The test suite covers 14 desktop, mobile, chat-management, streaming, keyboard, persistence, and automated accessibility scenarios.

Astryx's optional documentation CLI requires Node 22.13 or later. The installed Vite version supports Node 20.19 or later.

## Architecture

- `src/components/`: desktop chrome, native chat components, searchable commands, settings, and the companion overlay.
- `src/hooks/useChatStore.ts`: typed chat state, cancellable token streaming, conversation management, and local persistence.
- `src/hooks/usePersistentState.ts`: validated preference hydration and debounced persistence.
- `src/data/conversations.ts`: seeded conversations, model capabilities, and clearly labeled mock responses.
- `src/types.ts`: shared application types.
- `src/index.css`: explicit Astryx stylesheet layers and token-backed component styling. All theme fonts are self-hosted.
- `src/themes/desktopMatcha.source.ts`: an official `defineTheme` extension of Matcha that inherits Neutral's density tokens, keeping the sidebar at 260px and the composer in place when changing themes. The adjacent CSS, JavaScript, and declarations are generated by Astryx's compiler.

## Verified Astryx API Differences

The brief references some APIs that are not published in Astryx 0.7.0. This project uses actual exports rather than creating lookalike replacements:

- There is no `Box` export from `@astryxdesign/core/Layout`. Layout uses `Layout`, `LayoutPanel`, `VStack`, and `HStack`.
- There is no `Tabs` subpath. Settings use `TabList` and `Tab` from `@astryxdesign/core/TabList`, paired with accessible tab panels.
- `ChatMessage` uses `sender="user"` and `sender="assistant"`. `role="user"` would be an invalid ARIA role.
- The `ghost` variant belongs on `ChatMessageBubble`, not `ChatMessage`.
- `Kbd` uses `mod` for the platform-aware Command/Control key.

The required reset, core, and neutral theme stylesheets are imported in order, followed by the Matcha theme. No StyleX compilation is needed because published components are precompiled. Application styling uses `className` and official semantic color, spacing, radius, typography, and motion tokens. There are no raw layout `div` elements in application JSX.

To regenerate the desktop Matcha theme with Node 22.13 or later, run `npx astryx theme build src/themes/desktopMatcha.source.ts --out src/themes/desktop-matcha.css --icons-specifier @astryxdesign/theme-matcha/built`. Do not hand-edit the generated files.

## Interactions

Conversation creation, selection, rename, pin, archive, restore, deletion, and JSON export are implemented. Chat supports cancellable streaming, regeneration, Markdown, native code blocks, copy actions, feedback, read-aloud, collapsible approach summaries, simulated tool calls, scroll-to-bottom, file metadata previews, slash commands, tokens, and input history.

Settings persist light/dark/Matcha theme, voice choice, sound, and data preferences. Command/Control+K opens search, Command/Control+N starts a chat, Alt/Option+Space opens the companion, and Command/Control+Shift+S toggles navigation. The sidebar overlays the content on compact screens.

## Demo Boundaries

- AI responses and tool executions are deterministic local mocks. There is no OpenAI API or live web search integration.
- File attachments retain name, type, and size only. File contents are never uploaded or analyzed.
- Workspace selection is a local UI preference, not a multi-tenant backend.
- Speech recognition and speech synthesis depend on browser support, installed voices, and microphone permissions. The browser's speech provider may use its own network service.
- Window close/minimize are reversible browser simulations; expand uses the Fullscreen API when permitted. OS-global shortcuts would require an Electron or Tauri host.
- This is an independent UI concept, not an official OpenAI product.

## Toolchain Notes

The CSS optimizer reports warnings for upstream Astryx's nested `@property` rules. They do not prevent the production build. The preinstalled single-file Vite plugin has an upstream `braces` dependency advisory; compatible security fixes have been applied elsewhere without downgrading or breaking the host's build plugin.
